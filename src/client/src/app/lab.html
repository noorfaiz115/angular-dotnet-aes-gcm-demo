How the session works

Ephemeral P-256 key agreement + HKDF creates separate AES-256-GCM keys for requests and responses. Keys stay in memory. Each message has a fresh nonce and an authenticated request ID.

Health and session setup are unencrypted protocol endpoints. HTTPS is required for deployment. Login and registration now use this same encrypted transport.
